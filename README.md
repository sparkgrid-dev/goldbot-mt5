# Gold Bot · MT5 Gold Scalper

Website for Gold Bot, an automated M1 gold (XAUUSD) scalper with a live dashboard for MetaTrader 5 on Windows.

- Website: https://maribeth22.github.io/goldbot-mt5/
- Download: see [Releases](https://github.com/Maribeth22/goldbot-mt5/releases/latest)
